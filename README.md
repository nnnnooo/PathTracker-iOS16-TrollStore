# 漫迹 Waytrace — iOS 16.0+ / TrollStore 适配版

基于 [lxyeternal/PathTracker](https://github.com/lxyeternal/PathTracker)（PolyForm Noncommercial 1.0.0 许可，仅限个人学习与自用）重构的 **iOS 16.0+（含 iOS 16.1.1）适配版本**，零第三方依赖，专为 GitHub Actions 云端打包 + TrollStore 永久安装设计。

## 底层架构适配（iOS 26 → iOS 16）
- **数据存储**：使用 iOS 原生 **SQLite3（WAL 模式）** 替换 SwiftData + CloudKit，避免 TrollStore 伪签环境下无 iCloud Entitlements 导致的闪退，并支持完整 `.sqlite` 本地备份与恢复。
- **后台定位**：使用 iOS 16 原生 `CLLocationManager` + `CLCircularRegion` 地理围栏 + `CLVisit` + 显著位置变化重写后台定位引擎。
- **逆地理编码**：使用 `CLGeocoder` + `MKLocalPointsOfInterestRequest` 替换 iOS 26 `MKReverseGeocodingRequest`。
- **地图与界面**：使用 `MKMapView`（含中国大陆 WGS-84 → GCJ-02 自动纠偏）+ iOS 16 原生 SwiftUI / Swift Charts / `ImageRenderer`。

## 已实现功能清单

### 核心基础（MVP）
- **全天自动后台定位与三档精度**：
  - **省电**：仅依赖系统「到访（CLVisit）」与显著位置变化，几乎不耗电（接近 Rond）。
  - **均衡（默认）**：移动时后台记录完整路线，同一地点停留满 10 分钟关闭 GPS 切换为 150 米地理围栏。
  - **精细**：连续高精度 GPS，路线贴合街道。
  - 支持定时暂停（1 小时 / 3 小时 / 明天早上 / 手动恢复）、GPS 跳点过滤、CoreMotion 出行方式识别、航线大圆弧与地铁断网补线。
- **每日时间线与停留地点识别**：按天浏览分色轨迹地图与全屏地图，自动识别店铺/景点/城市/国家，支持自定义地点名称与分类。
- **全部足迹地图与国家/城市统计**：支持「足迹光点 / 全部路线」切换，查看国家/地区与城市停留天数及历史明细。
- **从相册导入历史足迹**：本地扫描相册照片和视频 EXIF 坐标，自动聚类去重并按 3 公里网格批量识别城市与国家。

### 第 1 批增强（已上线）
- **旅程与手动高精度记录**：自动从足迹中发现离开常住地 80 km+ 的多日旅行（一键收进旅程）；支持手动开启/结束徒步、步行、跑步、骑行高精度记录，计算配速与累计爬升。
- **统计图表与里程碑**：基于 iOS 16 Swift Charts 的近 7 天 / 30 天 / 12 个月移动距离柱状图、出行方式占比条、旅人画像、「你的地面里程能走多远」（京杭大运河 / 66 号公路 / 318 国道 / 丝绸之路），以及 23 枚铜/银/金/铂金里程碑奖牌。
- **时间线纠偏与隐私区域**：点击「路上」路段可查看单段地图、平均/最高速度、修正出行方式或删除 GPS 漂移；停留详情支持添加备注和设置 300 米隐私区域（导出 GPX 与生成分享图时自动隐藏）。
- **GPX 导入 & 本地数据库备份恢复**：支持多选导入外部 GPX 文件（自动去重）；支持导出/恢复 `Waytrace16-Backup.sqlite` 完整本地备份。

### 第 2 批增强（已上线）
- **漫迹护照与印章（「足迹」页进入）**：
  - 支持 **4 种护照皮色**（酒红 / 藏青 / 墨绿 / 夜黑）切换与触感盖章动效。
  - **国家出入境章**：自动推算非主常住国每次到访的入境日期、停留天数与口岸城市。
  - **中国 34 省朱砂印**：京、津、沪、渝……34 个省级行政区自动点亮，已去过显示朱砂印、未去过显示压印。
  - **城市纪念章**：车站日期章风格，记录首次到达日期与累计天数。
  - **四至与套章**：自动计算最北/最南/最东/最西与最高点海拔，含跨赤道/北极圈/跨太平洋/跨年特殊纪念章及 10 套经典城市联合套章。
- **「那年今日」与「重逢」提醒（「今天」页）**：自动回顾往年同一天的足迹；时隔 1 年以上再次回到同一地点时弹出久别重逢卡片。
- **分享卡片与旅程明信片**：使用 iOS 16 原生 `ImageRenderer` 一键生成高清深色路线分享图（自动过滤隐私区域），支持直接分享到微信或保存相册。

### 第 3 批增强（已上线）
- **此生必去（「足迹」页进入）**：内置中国 100 处（含港澳台）与世界 100 处完整清单，提供深色夜空星图、100 格点亮进度墙、自动按足迹半径点亮、手动点亮（「我去过这里」）、想去清单（♡）以及一键跳转 Apple 地图导航。
- **旅行盲盒（「足迹」页进入）**：按可用时间（周边一天 / 周末 / 小长假 / 长假）与出行感觉（放空看水 / 出点汗 / 看老东西 / 人间烟火 / 奔向旷野）只从你没去过的地方抽一张登机牌，结合真实足迹给出推荐理由与玩法建议，支持收进登机牌夹并自动标记「在等你 / 已经到了」。

### 第 4 批增强（已上线）
- **签证夹（「足迹」页进入）**：
  - Apple Wallet 风格叠卡展示，按美签、申根、日签、英签、澳新电子签等自动配色并显示剩余有效天数。
  - **相机实时扫描机读码（MRZ）**：基于 iOS 16 原生 VisionKit `DataScannerViewController`，在本地实时解析签证底部两行 ICAO 9303 机读码并自动填充国家、签证号与到期日。
  - **申根 90 / 180 天与使用统计**：结合本地足迹自动计算过去 180 天申根区已停留天数及剩余额度，并统计每张签证有效期内已用入境次数与天数。
  - **本地到期提醒**：保存签证后自动注册到期前 90 天、30 天、7 天本地推送提醒。

## TrollStore 环境说明
- 由于 TrollStore 伪签 IPA 无法开启苹果付费开发者专属权限，原版中的 **iCloud / CloudKit 跨设备同步**、**平行足迹（CKShare）**、**Apple 天气（WeatherKit）**、**Apple 登录** 与 **Apple Watch 独立端** 不在本适配版范围内；数据迁移与防丢请使用「设置 → 本地备份与恢复（`.sqlite`）」。

## 云端自动编译与 TrollStore 安装
1. 推送代码到本仓库 `main` 分支，GitHub Actions（`macos-15`）会自动通过 XcodeGen 生成工程并编译无签 Release 包（已开启自动取消旧排队任务，只编最新提交）。
2. 在仓库 **Actions** → **Build iOS 16 TrollStore IPA** 运行记录底部的 **Artifacts** 中下载 `Waytrace-iOS16-TrollStore.zip`。
3. 解压得到 `Waytrace-iOS16-TrollStore.ipa`，隔空投送到 iPhone，用 **TrollStore** 打开即可永久安装。
